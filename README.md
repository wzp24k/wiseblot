# WiseBlot

WiseBlot 是一个免费、纯前端的 Western blot 模拟与蛋白分析工具。打开网页即用，无需账号、无需上传、无需服务器，适合教学、预实验方案设计与论文配图。

在线使用：<https://wzp24k.github.io/wiseblot/>

## 功能

- **WB 模拟器**：实时生成拟真 Western blot 膜图。可调曝光、抗体效率、转膜、上样量、背景、噪声、胶浓度、拖尾影、标尺字体；支持自由添加/命名泳道、设置靶蛋白分子量与表达量、显示或隐藏条带标注、导出无标注 PNG。
- **蛋白助手**：输入 UniProt ID 或蛋白序列，预测分子量、等电点、净电荷、氨基酸组成、常见修饰基序、推荐内参与胶浓度，并给出抗体检索与交叉反应风险提示。
- **实验记录向导**：7 步连贯流程（样本、裂解与定量、电泳、转膜、封闭与检测、抗体、结果与量化），带进度条、可检索填写、重复强度均值 ± SD / CV 分析、条带图上传与记录持久化。
- **试剂库**：内置 149 种常用 WB 试剂，可按名称/货号/品牌/成分搜索，按类别或流程步骤筛选，并与实验向导联动自动填充。
- **WB 决策 / 成本估算 / 教学考核 / 方案库 / 功能拓展**：实验风险预判、试剂耗材成本估算、多场景教学考核题库、文献化方案检索等扩展能力。

## 数据来源

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 蛋白序列/基因/分子量/修饰（64,430 条，7 物种） | UniProt REST | 公开，无需密钥；分块 JSON 离线使用 |
| 化学标识（CID/MW/SMILES/InChIKey） | PubChem PUG REST | 50 种纯化学物已核验 |
| 跨物种同源映射 | mygene.info + NCBI eutils | 运行期映射 |
| 抗体推荐 / WB 模型（9,142 蛋白） | Human Protein Atlas v25 | AUC 0.716 |
| 等电点/净电荷/组分 | 本地计算 | 与标准生化计算一致 |
| 抗体品牌 | CiteAb / Antibodypedia / HPA | 生成检索链接 |

> 计划中（需授权）：PhosphoSitePlus 修饰位点明细、HPA 之外的抗体商品目录。

## 本地运行

无需安装，直接打开 `index.html`，或用静态服务器：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

重建单文件版本：

```bash
node build.mjs
# 生成 dist/index.html
```

## 文件结构

- `index.html` 页面结构（模拟器、蛋白助手、实验向导、试剂库等）
- `styles.css` 样式
- `app.js` 全部逻辑（含中英文 i18n）
- `build.mjs` 打包为 `dist/index.html`
- `dist/index.html` 可部署的单文件
- `data/` 本地数据集（UniProt 分块、试剂库、manifest）
- `work-seed.js` / `reagent-seed.js` 内联到 `app.js` 的种子数据
